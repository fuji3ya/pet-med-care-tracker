# Tend Pets Asset Production Plan

These assets should be generated or sourced before moving from prototype to store-ready visuals.

## Needed Assets

| Asset | Format | Use |
|---|---|---|
| App icon | PNG, 1024x1024 | App Store and home screen |
| Pet avatar set | PNG/WebP | Dog, cat, rabbit, bird, reptile, small animal |
| App Store screenshot background | PNG | Screenshot composition |
| Vet Summary PDF preview | PNG/PDF | Paywall and Records |
| Empty-state pet photos | PNG/WebP | Onboarding and no-photo fallback |

## App Icon Prompt

Create a premium iOS app icon for "Tend Pets", a pet medication and care reminder app. Use a sage green background, a refined white circular Care Ring, and a subtle abstract pet-care mark. No text, no paw-dose cliche, no cartoon style, no gradients, no shadow-heavy 3D. Clean, trustworthy, App Store quality.

## Pet Avatar Set Prompt

Create six consistent premium pet avatar images for an iOS app: dog, cat, rabbit, bird, reptile, and small mammal. Realistic but softly simplified, warm natural lighting, isolated circular composition, calm healthcare-adjacent app style, no cartoon outlines, no text, no busy background. Palette should harmonize with warm off-white and sage green UI.

## Vet Summary Preview Prompt

Create a clean PDF preview image for a pet care app called Tend Pets. Show a one-page veterinary summary for a cat named Momo with sections for active medication, skipped care, weight trend, vaccine history, and owner notes. Warm white paper, subtle sage accents, no diagnosis or treatment recommendation language, premium iOS app quality.
