# Image Generation Prompt: Tend Pets Sales TOP Page

Use case: ui-mockup
Asset type: premium sales landing page top design mockup
Primary request: Create a high-fidelity sales TOP page design mockup for "Tend Pets", an iOS pet medication and care tracker. The page should sell the app with the same visual system as the iOS app mockups: Calm Clinical Companion, warm off-white, sage green, clean premium iOS product design, Care Ring visual anchor.

Design lock:
- Brand: Tend Pets
- App subtitle: Medication & care reminders
- Aesthetic: Calm Clinical Companion
- Warm off-white background #FAF9F6
- White surfaces
- Deep charcoal text #1F2420
- Muted secondary text #6E746F
- Sage green primary #2F6F5E
- Medicine blue #3E6FB6
- Food amber #B8792D
- Visit/vaccine violet #7A5DB5
- No purple-blue SaaS gradients
- No decorative gradient blobs
- No childish cartoon look
- No generic SaaS hero card clutter
- Use real app UI mockups as the hero visual

Scene/backdrop:
A polished responsive landing page TOP section shown as a desktop webpage mockup. Full-page website design on a warm off-white background with subtle editorial spacing. It should look ready for a paid iOS app launch.

Hero requirements:
- First viewport must clearly signal the product and brand.
- H1 must be the brand/product name or literal category.
- Use descriptive value props in supporting copy, not a vague slogan.
- The hero should include real iPhone app screens, not abstract illustrations.
- Show a hint of the next section below the fold.
- No card containing the hero headline; text sits directly on the page.

Desktop TOP page content:
- Header nav: Tend Pets, Features, Pricing, Privacy, Support
- Right nav CTA: "Get the app"
- H1: "Tend Pets"
- Subtitle / category line: "Medication & care reminders for every pet"
- Supporting copy: "Track doses, vet visits, vaccines, weight, food notes, and family care routines in one calm iOS app."
- Primary CTA: "Get the app"
- Secondary CTA: "See features"
- Trust note: "No veterinary advice. Just clear records and reminders."
- Hero visual: overlapping iPhone screens showing Today, Pet Profile, and Vet Summary with Care Rings
- Small feature row: "Medication reminders", "Family sharing", "Vet summary PDF", "Weight & vaccine history"
- Next section hint: a band or row beginning with "Built for daily care"

Style/medium:
High-fidelity web landing page design mockup, premium App Store marketing quality, clean editorial layout, calm healthcare-adjacent feeling. Use realistic iPhone mockups and tasteful pet photos/avatars.

Composition/framing:
Wide desktop screenshot-like composition, 16:9. The hero should feel spacious but not empty. Product mockups should be large enough to inspect. Avoid split-card look; make the app screens part of an immersive product composition.

Mobile preview:
Include a small secondary mobile webpage preview on the side or lower corner only if it does not clutter the composition. Desktop TOP page is primary.

Lighting/mood:
Soft studio lighting, gentle shadows around phone mockups, no heavy gradients.

Constraints:
- Must look like a sales TOP page for a real iOS app.
- Use consistent palette and component style with the iOS app.
- Do not use fake app store badges unless they look clean and minimal.
- Avoid generic AI SaaS landing page style.
- Avoid dark hero, glossy neon, or purple-blue gradients.
- No watermark.
- Text should be as clean and legible as possible; if exact text is hard, prioritize visual hierarchy and consistency.
